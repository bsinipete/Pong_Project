Pong Created in Unity 6.5 (6000.5.9f1)

Running the Program:
  - Double click the Pong_Project.exe file, the game will start immediately
  - Use “w, s” keys to move the left paddle, and “up, down” arrow keys to move the right paddle
  -	Press F to pause the game and bring up the control instructions, press F again to continue the game
  -	Once the ball hits one wall the game will freeze
  -	Press esc to exit the game at any time
  
Compiling the Program:
Compilation of the program requires Unity. If you do not own unity, see to the instructions below
  -	Download the .zip file from the Pong_Project repository
  -	Create a new Unity 2d project in a known file location
  -	Extract the .zip file into the location of the created Unity Project
  -	On the top left corner, select file -> build and run; create a Build Profile if needed -> build and run
  -	Select the file location for the built game

Downloading Unity:
  -	Visit https://unity.com/
  -	Navigate to the download Unity button and click it, the download will begin immediately pertaining to the version of computer you own.
      -	If the download does not begin, ensure you download the version with your correct OS
  -	UnityHubSetup-x64.exe will go into folders, navigate through this application
      - Choose the install location and click install
